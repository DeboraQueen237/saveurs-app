# saveurs-app
saveurs est une applications web de recette de cuisine moderne développé en HTML5, CSS3 , et JavaScript Vanilla. Elle permet aux utilisateurs de decouvrir, filtrer et sauvegarder des recettes de cuisines du monde entier , le tout dans une interface élégante, rapide et 100% responsive
