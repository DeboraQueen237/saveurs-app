# saveurs-app
saveurs est une applications web de recette de cuisine moderne développé en HTML5, CSS3 , et JavaScript Vanilla. Elle permet aux utilisateurs de decouvrir, filtrer et sauvegarder des recettes de cuisines du monde entier , le tout dans une interface élégante, rapide et 100% responsive
# 🍳 Saveurs — Application de Recettes de Cuisine

Application web développée à KEYCE Informatique par une équipe de 3 étudiants.

## ✨ Fonctionnalités
- Recherche en temps réel (titre, ingrédients, tags)
- Filtres par catégorie
- Calculateur de portions automatique
- Système de favoris (localStorage)
- Mode sombre / clair

## 🛠️ Technologies
HTML5 · CSS3 · JavaScript Vanilla · GitHub Pages
